모델 = yolo26n(A–G) · **yolo26l(H·I)**, seed 0, 데이터 파이프라인 동일. far = far-recall(<16px@640 GT, conf 0.25).
**AP·far는 전부 COCO 평가**(held-out test·faster-coco-eval·conf 0.25·IoU 0.5) = repo 상단 [마스터표](../README.md#정확도--마스터표-전-모델-통일-평가-held-out-test)와 동일 수치. 원자료 `reports/unified/*.json`. **미측정 셀 = "—"** (추정치 기입 없음).

## 표 2 — 비교쌍 해석 (변화 변수 1개 = 깨끗한 ablation)

| 비교 | 변화 변수 | 해석 가능 효과 | 비고 |
|---|---|---|---|
| A→C | 데이터(+ep 150→100) | 병합: Maciullo AP50 +30pt(0.523→0.826), DUT far −10.5pt | ep 비대칭은 노출량(0.7M→5.7M) 논거로 완충 |
| C→D | epochs만 | 300ep: DUT AP50 +4.1pt 회복, Maciullo −3.5pt | 깨끗함 |

| C→E | imgsz+P2 (2개) | **결합** +7.6pt (AP50-95), far +11.3pt | 분리 불가 — G 없이는 P2 몫 미확정 |

| E→H | 모델 스케일만 (n→l) | DUT AP50 +3.5pt·AP50-95 **+8.2pt**·far +2.7pt, Maci <8px 0.636→0.727 | 깨끗함. Maci far는 −1.0pt(동급) |

## 결론 구조 (주장 가능 범위)
- 측정 확정: 병합 효과(A→C), epochs(C→D), 해상도 단독(A→B — DUT 이득·Maciullo 무이득), 결합(C→E), 추론 해상도(E→F, H→I), **모델 스케일(E→H)**.
- 미확정: **P2 단독(G→E)** — 모든 문서에서 "960+P2 결합"으로만 서술. G는 on-demand.
- 전 모델 정면 비교(D-FINE 포함): 상단 [마스터표](../README.md#정확도--마스터표-전-모델-통일-평가-held-out-test). **D-FINE-L이 DUT/Maci AP50 최고(0.973/0.907)**.
