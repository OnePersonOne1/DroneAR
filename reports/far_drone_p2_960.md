# 원거리(소형) 드론 개선 — 1~3단계 결과

목표: 먼 거리 드론 미탐(FN) 감소. 지표 = **far-recall(<16px@640 GT)**.

## 1) FN 크기 분석 (문제 정량화) → `fn_size_analysis.md`
- 병합 모델이 원거리에서 양보했음을 실측: DUT far-recall old 0.925 > 300ep 0.876 > 100ep 0.820.
- <8px bin 전 모델 최약 구간 (Maciullo 0.27~0.45).

## 2) 재학습 없는 레버: 고해상 추론 → `sahi_bench.md`
- **hi1280 단일 패스: far 0.876→0.944 (+6.8pt), 5.3ms** — 클라우드 즉효.
- tile640(SAHI): far 0.932, FP/img 0.95(과다) — 네이티브 1280 입력에선 무의미. 4K급(ML2 원본)에서 재평가.

## 3) P2 + 960 재학습 (merged, 100ep/pat30/seed0, yolo26n 전이, 16.2h)

- **P2+960 = 학습 모델 중 전 도메인 최고/동급**: DUT mAP50-95 +4pt(vs old), Maciullo <8px 0.27→**0.64**.
- 4090 latency: **4.2±0.2 ms (236 FPS)** — 클라우드 경로 충분. (ML2 온디바이스용 아님 — 960+P2 연산량 ↑)
- caveat: imgsz 다름(960 vs 640)은 의도된 레버 — "해상도+P2" 효과 측정이 목적. seed/데이터/epochs 프로토콜은 100ep 런과 동일.

## 결론 (원거리 개선 권장 구성)
- **클라우드(4090)**: `merged-P2-960` 배포 + (DUT류 고해상 소스면) hi-res 추론 병용.
- **온디바이스(ML2)**: 기존 640 모델 유지(300ep) — P2/960은 연산량↑로 클라우드 전용.
